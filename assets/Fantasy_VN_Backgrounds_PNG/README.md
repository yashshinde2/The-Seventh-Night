# Fantasy Visual Novel Backgrounds

**48 painted fantasy backgrounds** — 24 scenes, each in a **day** and a **night** version, 1920×1080.
Made for visual novels, dialogue scenes, card games and RPG menus: no characters, no text,
and the lower third is kept calm so a dialogue box can sit on top.

## AI disclosure
These images were **generated with AI**: the open-weights **Krea 2** model (Krea 2 Community License,
which allows commercial use and gives the outputs to the user), from written text descriptions only,
then upscaled with **Real-ESRGAN** and resized. No reference images, no artist or franchise names,
no LoRAs or other style models were used. Every image was reviewed by hand and re-generated when it
contained text, people or anything unsuitable.
